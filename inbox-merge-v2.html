A · 右侧就是现在的通知列表，顶上加一排分类标签

行的样子和你截图里一模一样（头像、票名、「状态设为 已完成」、时间、状态图标、红色未读数）。顶上按类型切：全部 / 找你的 / 停了没交代 / 状态变化 / 做完。点左边看板任意一行，或点右边任意一条，右侧都会换成「只看这张票」：这张票的所有通知按时间排，点「← 全部通知」回来。

✓ 最像现在，改动最小；一次只看一类，干净　✗ 同时想看「找你的」和「停了的」要来回切

B · 同一条列表，按类型切成几段，一眼看全

不用切标签，列表从上到下分段：找你的 → 停了没交代 → 状态变化 → 做完。每段标题能点开/收起，「做完」默认收起。点击行为和 A 一样，进「只看这张票」。

✓ 重要的永远在最上面，不用点就能看全　✗ 和左边看板的分道有点像，信息会重复一些

C · 按项目分组，类型用小图标标出

你截图里票名前面都带项目（Multica 魔改 / game / IPA-input / 通力电梯），C 就按项目分段，每行左边加一个类型小图标（@ 找你、⏸ 停了、✓ 做完）。顶上仍可按类型再筛一次。点击行为同上。

✓ 同时推几个项目时最好找　✗ 「谁在等我」被打散到各个项目里，紧急的不突出
