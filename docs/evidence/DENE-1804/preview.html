发钥匙 / 复制出来的接入说明（节选，三处同一段）

三、上手（这段说明由系统生成，命令清单看 multica capabilities，不用背）
1. multica overview --output json   # 看工作区全景：有哪些智能体、项目、聊天、自动化、技能、小队
2. multica capabilities             # 看命令能力地图：每条命令能看什么、能做什么、示例，按领域分组，标出外部 bot 钥匙能不能用；--output json 给程序读
3. multica <命令> <子命令> --help        # 单条命令的用法；拼错子命令时错误里会提示正确的那一条

CLI 同一段也能拿：multica bot guide [bot]；Web 走 GET /api/workspaces/:ws/bots/setup-text（owner/admin，人类登录）。
