项目可以只用指定的几个智能体干活

一句话：给项目定一份「执行人名单」，系统自动派活时只在名单里挑；名单里的人都忙不过来，就停下来说明原因，不去找名单外的人。

打个比方：就像给一个保密项目发门禁卡，只有持卡的几个人能被叫进屋干活；持卡的人都请假了，宁可先停工，也不随便拉外人进来。

结论

做好了，电脑、手机网页、手机 App、命令行四处都能看和改。合并上线后，会把这三个智能体写进那个项目：拉蒂兹、破甲孙悟饭、破甲特兰克斯。

对你有什么变化

以前
这个项目的新任务、新聊天，系统可能派给工作区里任何一个合适的智能体，名单外的也会被拉来兜底。
以后
只会派给名单里的三位。三位都不能接时，任务里会写一句「本项目限定执行人名单，名单外席位不兜底」，然后停下。

系统挑人时怎么走

新任务 / 新聊天 / 接着做 / 升档 / 额度用完换人 / 验收 / 顾问
先看项目有没有名单 → 没有：照旧挑人
有名单 → 只在名单里挑能接活的
名单里都接不了 → 停下，写清原因，不往外找

你直接 @ 某个智能体、或者手动指派，不受名单限制。已经在干活的智能体不会被换掉，已有任务和聊天也不会被取消；但以前定好的验收人如果不在名单里，到验收时会换名单里的人来验。一个聊天同时挂了几个项目，要几份名单都认可的智能体才能接，没有就不开。只有工作区管理员能改名单。
