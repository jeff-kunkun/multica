规则原文   智能体只能看，不能改。      （任务令牌的 run 打开设置页）

命令行（Agent 不开浏览器也能查、能改）

multica workspace routing policy show                       # 原文、规则行（来源句 + 默认/模型解析/手改）、版本和改动记录
multica workspace routing policy preview --text "数据处理交给 Codex。" --output json > preview.json   # 只解析，不写入
multica workspace routing policy apply --file preview.json   # 确认生效，记一版
multica workspace routing policy apply --reset               # 恢复默认

服务端校验：至少一条规则、系列和档位必须在本工作区的阶梯里、没变化不记版；任务令牌只能 show。手机端：行内控件自动换行堆叠，原文框和按钮撑满宽度，改动记录纵向排。apps/mobile 原生 App 没有路由设置页，不改。
