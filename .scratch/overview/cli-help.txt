Read agents, projects, active chats, automations, skills, squads, runtimes,
linked workspaces and external connections from one permission-filtered snapshot.
Restricted sections are listed in omitted_sections. Filters accept an ID or name
and are resolved by the server; combine them to narrow the workspace map.

USAGE
  multica overview [flags]

FLAGS
      --agent string     Only include records related to this agent ID or name
      --compact          Return names, IDs and key fields only; print one line per item
  -h, --help             help for overview
      --output string    Output format: table, json (default "table")
      --project string   Only include records related to this project ID or name

INHERITED FLAGS
  --help   Show help for command

EXAMPLES
  multica overview
  multica overview --output json
  multica overview --project "My project" --compact
  multica overview --agent "My agent" --output json

LEARN MORE
  Use `multica <command> <subcommand> --help` for more information about a command.
