## 直连能力与验收

用真 Grok 云电脑 + 真 Multica，以个人令牌身份逐项验证：
1. 列出/搜索聊天并读历史。
2. 列出、筛选、搜索任务。
3. 读取完整描述、全部评论（含附件）、状态卡。
4. 与孙悟空自媒体新开/继续聊天，同一轮识别本次最终回复；必要时补个人身份 CLI 入口。
5. @ 孙悟空之外的智能体成功，不设置桥接专属名单。
6. 记录请求与结果时延，在线目标 ≤1 分钟；区分请求 ack 与最终回答，不能宣称直连消除了排队/模型耗时。
7. 修改状态、负责人、标题、描述、标签、优先级。
8. 关单、重开；合并按 CLI/服务端现有契约。
9. 指派与开工（assign/rerun）。
10. 上传图片与日志文件，挂入评论/聊天，在网页可见。
11. 修改与撤回 Bot 发出的留言。
12. 沙盒中验证删除或配置操作可按个人权限直接执行，无额外确认档；还原可还原的测试设置。

更新 README、Grok 长期指令与可复用技能，去掉四动作/不保存 token 的旧规则。个人令牌可存在指定受保护配置中，不能打印或进入 Git、评论、信箱正文；检查权限、持久化与意外泄漏，不再要求扫描 0 条 Multica token。验收末尾请 Kun 手机体验。
